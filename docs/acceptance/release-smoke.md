# 默认发布冒烟与 Actions 接口验收

日期：2026-11-15。交付范围为固定冒烟脚本、编写约束、全量仓库 CI 和生产调用接口。用户随后授权将当前工作区全部业务改动一起提交，并尝试 GitHub 合并及线上自动化；远端执行结果另行记录，下面的本机结果不代替线上验收。

## 已实现

- `scripts/release/smoke.mjs`：最多六次串行 GET；健康、匿名鉴权拒绝、指定用户及默认工作区、工作区列表、运行中任务列表均验证结构与语义。
- 单次请求（含正文）最多 5 秒，全程最多 30 秒，单响应 64 KiB，无重试或重定向。生产 HTTPS；凭据缺失、失效或用户不匹配即失败。
- 只输出固定检查名、错误码、HTTP 状态和耗时，不输出 token、身份 ID、URL、业务正文及原始异常。正常鉴权会更新专用会话 `last_seen_at`，不声称完全零数据库写入。
- `.github/workflows/release-smoke.yml`：可复用生产冒烟接口，固定候选完整 SHA，使用调用方提供的当前有效专用账号凭据；不自动登录、刷新、部署或清理。
- `.github/workflows/release-smoke-check.yml`：PR、main push 和手动运行的 `Server CI`；类型、Lint、构建、全部单元/契约及独立 PG/Redis 集成检查，不读取生产秘密。
- 后续 AI 扩展检查遵循 `scripts/release/AGENTS.md`，开发阶段生成和审查代码，线上仅执行审核后的脚本。

## 本机证据

| 检查 | 结果 |
| --- | --- |
| 专项 loopback HTTP 替身测试 | 27/27 通过，包括超时、超限、重定向、错误响应、CLI 退出及脱敏 |
| 完整 unit/contract | 45 文件、513/513 通过 |
| 真实独立 PG/Redis 集成 | 19 文件、247 通过、1 项真实 Milvus 跳过 |
| 其中真实 API 冒烟 | 4/4：正常六次 GET、身份不符、撤销会话、过期会话 |
| 类型检查、完整 Lint、构建 | 全部退出 0；构建有既有 Vite 指令忽略和大 chunk 提示 |

真实集成使用本机 Colima、带本轮标签的临时 PG/Redis、tmpfs 和随机回环端口，不读取真实 `.env`。断言业务表行数及账号/工作区/会话字段不变，仅正常更新 `last_seen_at`；失效会话不刷新、不新建。结束清理自身临时容器，既有六个容器的 ID、启动时间及重启次数不变。云供应商、解析、短信、模型和生产接口均未调用。

本地脱敏日志、退出码、文件哈希和汇总位于 `.local/release-smoke/`。只读核对 App 的 `api_endpoints.dart` 和 `http_auth_repository.dart`，哈希与已有记录一致，未修改 App。

## 仍待接入

专用账号凭据自动取得由用户明确暂缓。部署 workflow、目标服务器执行通道、生产配置及切流仍需接入。验收脚本的 SHA 只固定检查代码，不能证明目标已经运行该版本；调用方须先核对镜像和部署结果。当前版及上一成功版的保留/清理属于发布入口，不在冒烟里实现。

完整工作区发布还须只读核对目标库的迁移记录/结构和文档节点 `async` 配置；本机开发库的同步证据不代表目标服务器。不得为通过预检而重写生产迁移校验和。
