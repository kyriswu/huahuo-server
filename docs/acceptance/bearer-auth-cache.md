# Bearer 会话缓存验收

现有及新增环境使用 Nginx 原生 `auth_request` 调用 Server。Server 使用 Redis 缓存首个通过验签和数据库检查的 Bearer 会话，后续命中时跳过入口会话查库。缓存最长 15 秒并受令牌和会话到期时间约束。身份头生成、业务事务授权及 Studio Cookie 流程见[入口鉴权契约](../runbooks/gateway-auth.md)。

刷新、注销及刷新令牌复用检测在提交后更新缓存。0018 为数据库账号和会话状态写入提供提交后的失效通知，复用现有用户会话查询索引。迁移只创建函数和触发器，数据回填为零。通知或缓存写入失败时由原始到期时间限制旧授权窗口。
