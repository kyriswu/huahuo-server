## 代码范围

- 删除原代理的镜像目录、双槽位、Dashboard、路由卷、切流控制器、分支探测、专项 CI 入口、环境模板及运行手册。Compose 恢复四角色与一次性 migrate，API/Admin 各自保留受限业务端口。旧压力基准作为历史测量保留，不是当前部署方案。

Nginx 配置、验证脚本和宿主发布候选均在仓库外维护。独立上游文件让公开 API、鉴权与受限内部 API 使用同一发布目标；宿主执行器候选仅切换该文件，删除旧 vhost 首次兼容路径。没有在 macOS 安装 Nginx、修改系统服务或安装 Homebrew 包。
