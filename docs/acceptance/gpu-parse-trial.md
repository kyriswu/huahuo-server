4. 首个受理最小按量实例 `eci-2ze1sf3dfaie0gr1h3m2`为第二档，拉取5m6.385s；Exec脚本超过长度限制，尚未加载模型就释放，双查0。短Exec改为≤256字节、幂等分片覆盖、重组与SHA-256核对，本地54KB往返与丢响应重试通过；随后当前实例真实传输成功。
