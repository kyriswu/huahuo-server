# P06 知识图谱标签化补充要求（持续生效）

本文件保存用户对 P06 的补充决定，优先于原总规范、架构和阶段计划中相冲突的图谱/检索设想。不改变阶段编号，不重做 P01—P06；本轮完成后停止，下一阶段仍为 P07。用户下次明确说“继续下一阶段”后才进入 P07。

## 范围与工程约束

只修改现有 huahuo-server；../huahuo-app 只读参照（https://github.com/kyriswu/huahuo-app），不改 Flutter UI、不重建工程、不重新开展全仓分析。先读适用 AGENTS、progress、P06、契约与相关实现。复用 Fastify + PostgreSQL + Redis 和同一 Compose 内独立 api-server、worker、admin、scheduler 等容器。保留原数据、正文 revision、迁移历史及其他模块，不删库/卷，不操作其他项目。

## 最终业务定义

保存素材 → 用户手动填写标签或系统提取标签 → 标签及素材关系进入 PostgreSQL → 前端展示分类和关联图谱。权威关系只有“某份素材拥有某个已生效标签”；素材节点对应真实文章、笔记、转写等资产，不复制正文、不建第二个知识资产库。

永久禁止在本项目后续阶段自行增加 Embedding、向量索引、pgvector、Rerank、GraphRAG、语义问答知识库、Dify Dataset 或知识检索节点。正常 Chat、Dify 创作、摘要和关键词搜索保留。Agent 通过受控 API，按指定素材、标签、关键词、时间和来源读取授权原文辅助创作，不允许任意 SQL，不建向量知识库。

A《如何用 AI 写作》有 AI/内容创作；B《短视频脚本的方法》有 内容创作/短视频；C《旅行日记》只有旅行。A/B 只因“内容创作”关联，C 不强行连线。主题聚合可以查看对应素材；素材派生边必须列共同标签；确有 App 标签间连线需求时仅表示同篇素材的标签共现。只提供当前 App 需要的一套投影，不让模型任意抽实体、编造因果或语义相似度。已有来源引用继续原用途，不混作标签关系、不批量删除。

## 人工管理与一致性

支持查看、增加、修改、移除某篇素材标签。移除只解除此篇映射，不删文章或其他文章标签；修改默认只修改此篇，不全局重命名。规范化/去重限定同用户授权工作区，不跨用户合并或语义同义词合并。

自动标签通常 3—5 个，默认最多 5 个，内容不足允许更少。人工上限按实际 App/接口（本次源码为最多 20 个，每个 1—24 Unicode 字符），超限明确拒绝，不静默截断。无标签仍可保存、阅读、搜索，在图谱中为孤立节点或未分类内容。

用户修改过后，重新提取仅提供建议，明确应用前不得改现有集合。旧任务、重试、重复回调不能恢复用户删除的标签。首次自动提取允许直接写入，必须原子检查正文版本、标签集合版本/人工状态、删除状态和任务 attempt/lease，并与业务写入、结果和结算使用既有事务/幂等机制。

## 提取接口与 Worker

复用 TagExtractor/Provider、Task/Outbox/Worker。先保存原文，再异步提取；输入身份、正文版本、标题与可读正文，输出经过类型/数量/长度/重复校验的集合。失败不影响读取、不清空标签，不在每次打开图谱、文章、聊天时重提取。

可配置的直接 LLM 和 Dify 工作流只是标签提供方，不能硬编码进资产/图谱业务。长文可有限分段、合并去重并控制调用预算，分段仅作标签处理，不持久化向量切片。复用用量计量/重试，不重复落标签、计数、计费。

不可读 PDF/DOCX、未转写音频保留真实待处理状态、原文件引用，可人工打标签；不能从文件名伪造读过正文，不扩展 OCR、图片/视频语义理解。不可读内联文件须先通过 P05 上传持久资源再引用，不能返回成功却丢弃原文件。

本轮只完成业务、可替换接口和测试。真实模型/Dify 在 P08 接入；未配置标未配置，fixture 显式选择且生产禁用，不擅自付费调用。

## 图谱查询与契约

有效标签新增/修改/移除或素材删除，主题计数、共同标签证据和边同步变化：唯一共同标签消失则边消失，仍有其他共同标签则更新证据。按有效授权素材身份去重计数，不按 revision 计篇数。成功保存后的读取不得命中旧关系缓存，迟到任务不能恢复已删关系。

复用素材—标签映射，按需返回主题和局部关联；禁止全标签全素材预生成两两边。节点、边、分页有预算，高频标签明确是否更多，局部数量不冒充总量，不传全库全文给手机。保留关键词、正文、时间、来源查询，不标 semantic。

接口核对真实 App 请求和解析器，严格白名单对象不能随意加字段；后端不重写 3D/交互。客户端尚未接线的能力单独登记，不以后端 fixture 通过冒充完整 App 验收。

## 八项验收

1. 无模型也可保存、人工增删改标签、读图谱。
2. A/B 正确关联，C 不错误连线。
3. 移除 A 共同标签后相应边消失，B 不变。
4. 人工修改后旧任务、重复完成和重提取不覆盖。
5. 正文更新/素材删除后旧结果无效。
6. 提取失败、无标签、待解析材料不丢原文。
7. 标签/搜索/计数/图谱严格隔离用户和工作区。
8. 高频标签局部返回、总计数和缓存失效正确，原 P06 测试不回归。

实际检查代码、必要迁移、接口与测试，已符合者复用，不新增重复结构交差。
