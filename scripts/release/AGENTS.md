# 发布冒烟脚本约束

这里的默认冒烟脚本由开发阶段生成、审查和测试，生产只执行已审核提交的固定代码。不得在 Actions 中临时调用 AI 生成并执行生产测试。

- 默认只使用 `smoke.mjs` 中审核过的 GET 路径；新增检查同时更新测试和 `docs/runbooks/release-smoke.md`。不得从 ENV、用户输入或远程文件接收任意 URL、HTTP 方法、SQL 或 shell 命令。
- 仅使用预先准备的专用验收账号、默认工作区和当前有效 access JWT；验证返回的用户和工作区身份。不读取真实用户资产，不创建账号或刷新会话，不保存凭据。
- 默认六次请求，串行执行，无重试；单次请求含响应正文最多 5 秒，全程最多 30 秒，单响应最多 64 KiB。允许缩短预算，不允许通过 ENV 放大。
- 禁止调用短信、支付、模型、解析、上传、删除或云资源开停接口。GET 鉴权会更新专用会话的 last_seen_at，应如实说明，不声称零数据库写入。
- 禁止跟随重定向；生产只允许 HTTPS，HTTP 只用于回环隔离测试。凭据仅发往固定认证路径。
- 验证响应结构和业务语义，不能只验证 HTTP 200。任何检查失败立即停止，退出非零；不得跳过缺失/过期凭据而报告成功。
- 日志和报告只包含固定检查名、状态、固定错误码、HTTP 状态及耗时，不打印配置、URL、JWT、账号 ID、响应正文或原始异常。
- 冒烟不执行部署、清理或数据库迁移。调用方应在部署及切流完成后调用，清理必须依赖冒烟成功；失败保留旧版本。当前版和上一个成功版本的镜像保留规则属于发布调用方。
- 测试只使用 loopback 替身或独立测试 PG/Redis。不得在 CI 的脚本自测中访问生产或带入生产凭据。
